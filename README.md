# Rogue Reproductive — PRE-RELEASE (v2)

> ⚠️ **Versión preliminar / en desarrollo.** Esto NO es la versión final del juego:
> faltan contenidos, puede haber bugs y todo puede cambiar.

Segunda versión del roguelike inspirado en Soul Knight, con temática para adultos (+18).

## Cómo jugar
1. Instala [Godot 4.7](https://godotengine.org/download).
2. Abre Godot → *Importar* → selecciona `project.godot`.
3. Pulsa **F5**.

**Controles:** WASD/flechas mover · Click/J/X atacar · Espacio dash · E interactuar · Q usar objeto · Esc pausa. Compatible con mando.
